# Учёт смен — Telegram-бот (облако)

Бот считает смены, часы, зарплату и авансы. Работает на GitHub Actions: каждые 10 минут
запускается процесс, который забирает новые сообщения Telegram, отвечает и сохраняет
состояние в зашифрованный файл `state.enc`.

## Как это работает

- `.github/workflows/bot.yml` — расписание (каждые 10 минут) + ручной запуск.
- `bot.py` — вся логика: меню, сотрудники, смены, авансы, отчёты.
- `state.enc` — состояние (шифр Fernet, ключ в секрете `STATE_KEY`).

## Секреты репозитория

- `BOT_TOKEN` — токен от @BotFather.
- `STATE_KEY` — ключ шифрования состояния (Fernet).

## Ручной запуск

`Actions → uchet-bot → Run workflow` — проверить, что бот живой.
